# Third-Party Components and Licensing

The project's own code is **BSD-3-Clause** (see [LICENSE](LICENSE)). The
distribution is deliberately **multi-licensed**: bundled third-party
components keep their original licenses, which spreads legal risk and lets
each layer use the best available source.

## Policy

1. The **kernel, drivers and base image** prefer BSD/MIT/Apache-2.0 code.
   In particular the network stack is NetBSD-derived (BSD-2/3) rather than
   Linux `net/` (GPL).
2. **Copyleft programs** (XFCE, Qt, tcc as an executable) may ship in the
   optional developer image as separate programs, never linked into the
   kernel; their sources are provided alongside.
3. Every bundled component is registered below with version/origin, license,
   usage and modifications; imported sources keep their upstream headers.
   Imported files are **exempt from the 300-line rule**; wrappers we write
   are not.
4. Test-only tools (QEMU, OVMF, clang, `rustup`) are not redistributed and
   are therefore not registered.
5. A component may only be added together with its register entry and, when
   required, its license text next to the import.

## Runtime-fetched components (not bundled)

The MinGW toolchain (`tools/mingw_bootstrap.sh`, M15) is downloaded and
built by the user at runtime into `/opt/mingw`; it is not part of any
shipped image, so its licenses (GPL/LGPL for GCC/binutils, public domain for
MinGW-w64 headers) apply to the user's local build only. The script prints
the source URLs and license names before building.
