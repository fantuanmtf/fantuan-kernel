fantuan-kernel 开发规划 CSV 套件

编码：UTF-8 with BOM，适合 Excel / LibreOffice 打开。每个文件为独立 CSV 表；CSV 不支持多工作表，因此按主题拆分。

文件：
01_开发想法表.csv：想法、技术取舍、实践方法、验收标准与风险。
02_后续实施路线表.csv：阶段、任务、依赖、操作步骤、验收标准与粗略工作量。
03_语言与工具优先级.csv：Rust/C/Python/汇编/Shell/C++ 与构建工具的使用顺序及边界。
04_决策记录.csv：可维护的工程决策摘要、理由、暂缓选项和复查条件。

状态说明：内容基于 2026-10-14 浏览到的公开仓库文档整理；本次没有在容器内克隆、编译或运行项目。仓库 PROGRESS 文档的状态是文档声明，不等于本次复测通过。开始开发时应首先执行路线表 R-001，更新真实基线。

“决策依据”是供开发维护的简要摘要，不是隐藏的逐字思维记录。
